# Data Scraping from Quizlet to make a Random Word Generator

This repository is for more efficient and simplified studying. 

With the free version of Quizlet, it is incredibly slow due to the overload of advertisements. To fix this issue, I exported the csv file from 7 different vocab units and created a random word generator that runs through the words and definitions very efficiently. 

Utilizing python, I was able to cycle the entire vocab of 555 words + definitions in less than 5 minutes. To actually study effectively, an individual would only need about 20 minutes to go through 100 words.
